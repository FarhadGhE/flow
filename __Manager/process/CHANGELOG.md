# Changelog

Each version lists what changed and its **Project changes**: what an upgrade must also change in a
project's own files (`upgrade.md` step 5). When there are none, it says so.

## 0.1.0 — 2026-10-04

First version.

- Setup in two rounds: four questions, read-only discovery, a proposal the user approves, then the
  build and a project README.
- Direct turns, coordinated turns, and coordinations with an authority block, checkpoints and a
  coordinator log.
- No scripts: exact Git commands, an audit at the start of every session and a receipt line at the end
  of every round.
- Per-machine commands and expert agents for Claude Code and Codex.

Project changes: none.
